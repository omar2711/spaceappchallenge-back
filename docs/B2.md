## Contratos y uso desde B3

`app.b2.models` define contratos Pydantic v2 JSON/OpenAPI, con campos adicionales
prohibidos, valores finitos y procedencia obligatoria (`synthetic`/`observation`).
Los servicios no importan FastAPI ni B1/B3. No se registran endpoints nuevos.
B3 puede importar `summarize_curve`, `process_spectrum`, `difference_images`,
`query_splices` y `prepare_comet` desde sus módulos correspondientes. Si usa
endpoints async, ejecutar FITS y consultas síncronas en un thread pool; mapear
errores de validación, archivos y red en su propia capa HTTP.

```python
from app.b2.models import LightCurve
from app.b2.lightcurves import summarize_curve

def analyze(payload: dict):
    return summarize_curve(LightCurve.model_validate(payload)).model_dump(mode="json")
```

- Curvas RW Aurigae/R Draconis: ordenar épocas MJD, media ponderada, error de
  media, amplitud pico a pico, chi cuadrado frente a una constante y n-1 grados
  de libertad. No estima períodos ni declara eventos. Errores independientes;
  magnitudes se promedian en magnitudes, no como flujo medio. No mezclar bandas,
  sistemas fotométricos, componentes de RW Aur ni escalas temporales.
- Espectros: muestras 1-D calibradas, longitud de onda de vacío en micrómetros,
  flujo y errores positivos de una sigma. Normalización por continuo aportado,
  tau=-ln(F/C), sigma_tau=sigma_F/F. Continuo considerado exacto; no hay ajuste,
  extracción automática, covarianza ni identificación de moléculas. Flujos cero
  o negativos se rechazan para este cálculo; no son detecciones ausentes.
- Imágenes: `science - reference_scale * reference`, conversión de BUNIT,
  comprobación estricta de WCS y dimensiones; NaN/Inf salen como null. No realiza
  registro, igualación de PSF, sustracción de fondo ni significancia de residuos.
  No se propagan errores de imagen en esta fase. WCS idéntico es una comprobación
  de metadatos, no prueba empírica de registro astrométrico o calibración.
- SPLICES: consulta cónica TAP oficial, límite explícito y advertencia conservadora
  de posible truncamiento. Cliente httpx inyectado (usar timeout explícito, p.ej.
  `with httpx.Client(timeout=30) as client:`). Sin consultas al importar módulos.
  No resuelve nombres ni confirma identidad de objetos. Coordenadas ICRS en grados.
- Cometa: lista tipada de requisitos; no calcula efemérides ni composición.

## Conexión con B1: propuesta pendiente de acuerdo

No se impone un formato a B1. Un adaptador deberá convertir su manifest a
`FitsAsset`; `DifferenceRequest` agrupa dos assets. Ejemplo **sintético**, sin
archivos observacionales asociados:

```json
{
  "science": {
    "path": "synthetic/science.fits", "hdu": "SCI",
    "provenance": {"kind": "synthetic", "source": "integration example only"}
  },
  "reference": {
    "path": "synthetic/reference.fits", "hdu": "SCI",
    "provenance": {"kind": "synthetic", "source": "integration example only"}
  },
  "reference_scale": 1.0
}
```

```python
from pathlib import Path
from app.b2.models import DifferenceRequest
from app.b2.images import difference_images

# root viene de configuración del servidor, nunca del cuerpo HTTP.
def subtract(manifest_pair: dict, root: Path):
    return difference_images(DifferenceRequest.model_validate(manifest_pair), root)
```

Solo se leen rutas relativas resueltas dentro del root autorizado (también se
comprueban escapes por enlaces); no se descargan archivos ni se escriben FITS.
HDU explícito; no se adivinan nombres o posiciones. La cabecera de ese HDU debe
tener WCS celeste y BUNIT. Si B1 conserva metadatos en PRIMARY, deberá acordarse
un adaptador explícito; no hay herencia automática de cabeceras.

Coordinar con B1: versión de manifest, identificadores/URI oficiales, checksum,
release y nivel de producto, target/componente, HDUs SCI/ERR/DQ, política de flags,
unidades, tiempos y escala, bandas, calibración espectral, WCS/PSF y fondo.
B1 debe preparar los píxeles inválidos como NaN y proporcionar imágenes alineadas
y comparables. Para espectros 1-D, B1/adaptador convierte sus columnas y unidades a
`Spectrum`; no existe todavía un lector genérico del formato SPHEREx. Para curvas,
debe aportar fotometría calibrada con incertidumbres; no se extraen aperturas aquí.
No sustituir mapas de longitud de onda de SPHEREx por un eje lineal supuesto.

Coordinar con B3: rutas HTTP, límites de tamaño/paginación, errores, almacenamiento
de resultados y visualización de procedencia. B3 debe distinguir datos sintéticos,
resultados descriptivos, bandas esperadas y detecciones publicadas. Para el cometa
se necesita geometría del observador por época y registro de objeto móvil.

No se incluyen observaciones ni resultados atribuidos a NASA en este paquete.

## Verificación

```powershell
venv/Scripts/python.exe -m pip install -e ".[dev]"
venv/Scripts/python.exe -m pytest -q
venv/Scripts/python.exe -m mypy
venv/Scripts/python.exe -m compileall -q app
```

Los tests usan exclusivamente números analíticos, FITS temporales y respuesta
TAP simulada. Verifican cálculos, validación, WCS/unidades, rutas, propagación de
errores de red, preparación del cometa y compatibilidad de contratos con FastAPI.
No validan calibración real, resolución temporal/espectral, identificación de
moléculas, ni disponibilidad del archivo. Tampoco certifican otras versiones de
Python. NumPy y Astropy son las únicas dependencias científicas añadidas; Astropy
incluye FITS y WCS. No se añade Matplotlib ni Astroquery porque no se usan.

Resultado local (Python 3.14.7): 25 pruebas aprobadas, mypy sin errores en ocho
archivos, compileall y pip check correctos. Pytest requirió ejecución fuera del
sandbox por restricciones del entorno temporal. Se observó una advertencia de
deprecación del TestClient de Starlette por su uso de httpx; las pruebas HTTP
pasaron. No se ejecutó una consulta real a TAP ni se descargaron observaciones.
